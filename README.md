# Pakistan Flood Rainfall Prediction

Linear regression model predicting daily rainfall (mm) using 
Pakistan weather data (NASA POWER, 1981–2026), based on 
temperature, humidity, and wind-speed features.

## Dataset
NASA POWER daily weather data for Pakistan flood-affected regions

## Approach
Feature scaling → train-test split → Linear Regression → 
evaluation (MSE, R²)

## Tools
Python, pandas, scikit-learn, matplotlib, seaborn
